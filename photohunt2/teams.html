⚠️ Groups beyond A, B, C need one database change

The database only accepts A, B, and C right now. A student on any other group would shoot happily all day and then fail to upload. To allow more, run this once in the Supabase SQL editor for the whydah-photo project:

alter table public.hunt_submissions drop constraint if exists hunt_submissions_team_check; alter table public.hunt_submissions add constraint hunt_submissions_team_check check (team ~ '^[A-Za-z0-9][A-Za-z0-9 _-]{0,15}$');

Until then, stick to A, B, and C — removing groups works fine either way.
