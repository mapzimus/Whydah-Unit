# The Whydah Gally

A source-conscious site about the **Whydah Gally** — an 18th-century slave ship turned pirate ship that wrecked off Cape Cod in 1717.

**[whydahstory.com](https://whydahstory.com)** (GitHub Pages).

The front door is the ship: the voyage, the wreck, the 1717 chart that found her. A new spatial telling of that voyage is marked **coming soon** at [`/gis/`](./gis/). Until then the [19-stop flythrough](./flythrough.html), [Maps](./maps/), and [Map Studio](./map-studio.html) are the working cartography.
